# Matematikos praktika

Atidaryk `index.html` (arba naudok VS Code Live Server). Nieko diegti nereikia.

- 11 ir 12 klasės suskirstytos į B (bendrąjį) ir A (išplėstinį) kursus.
- Temos pateiktos pagal [Emokyklos matematikos programą](https://emokykla.lt/bendrosios-programos/visos-bendrosios-programos/5). Temų pavadinimai susmulkinti taip, kad būtų patogu naudoti uždavinių banke; kai kurie yra apibendrinti. Patikslinimus galima daryti `questions.js` faile.
- Ne visoms temoms uždaviniai įkelti. Tuščios temos pažymimos brūkšniu, o jas pasirinkus matomas paaiškinimas.
- Teisingai išspręsti klausimai išsaugomi localStorage vienoje naršyklėje. Senosios 15 uždavinių versijos progresas perkeltas į atitinkamas 11 kl. temas.
- Norint pridėti uždavinį `QUESTIONS` masyve, įrašyk unikalų `id`, `course` (`11-A`, `11-B`, `12-A`, `12-B`), `topic` (tiksliai kaip `CURRICULUM`), `question`, keturis `options`, ir `correct` indeksą 0–3.
- A ir B kursuose tie patys 11 kl. pradiniai uždaviniai pateikiami kaip atskiri įrašai su atskiru progresu.
